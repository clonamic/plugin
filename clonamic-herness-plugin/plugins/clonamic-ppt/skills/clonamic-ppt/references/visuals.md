# Visuals (v1)

No image search or image generation.

- Prefer metric_card, comparison, process_steps, or a compact table over a decorative picture.
- A chart is allowed only when the user supplied a numeric series. Put it in a `table` or `metric_card` in v1; the engine does not invent series.
- Quotes need attribution. Unattributed quotes are forbidden.
- Screenshots only if the user attached the file; then the engine is not used for photos in v1 — describe in notes instead.
