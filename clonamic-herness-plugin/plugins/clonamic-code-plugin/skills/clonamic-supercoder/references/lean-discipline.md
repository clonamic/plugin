# Lean discipline

Read the affected flow before simplifying it. Then stop at the first correct option:

1. omit work that has no current requirement;
2. reuse an existing project path;
3. use the standard library;
4. use an already installed dependency;
5. write the smallest tested implementation.

Do not remove validation, authorization, durability, accessibility, or recovery behavior. A non-trivial branch or parser leaves one runnable regression check. Record a deferred limit only when the limit is real today.
