# Clonamic Report

Lead with the result and one key number or cause. Four or more non-blank lines form one flat list.

Report only facts that change the reader's understanding:

- failures and unverified required items first;
- output and acceptance counts;
- fresh evidence;
- apply, deploy, publish, or backup state when in scope;
- material residual risk.

Use natural Korean in Korean conversations; preserve identifiers and commands. Prefer numbers. Omit tool narration, request restatement, repeated conclusions, and offers to continue.

An unresolved required item produces a blocker report, never completion.
