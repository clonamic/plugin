# 첫 실행 설정

`preflight` 결과에 `"first_run": true`가 있거나 사용자가 `설정`을 요청했을 때 쓴다. 질문은 한 번, 한 메시지로 모아서 하고 모든 항목에 기본값을 붙인다. 사용자가 "기본값으로"라고만 답해도 진행할 수 있어야 한다.

## 1. 질문 메시지

`preflight`의 `defaults`로 빈칸을 채워 그대로 보낸다. 감지 결과가 없는 항목은 그 줄의 괄호를 뺀다.

```text
작업 기록을 처음 설정합니다. 바꿀 항목만 답해 주세요. 답이 없으면 기본값으로 진행합니다.

1. 파트(역할)와 프로젝트 소개: 이 프로젝트에서 맡은 역할은 무엇인가요? 예: 백엔드 개발, 앱 프런트엔드, 데이터 파이프라인
   프로젝트를 모르는 사람에게 한 줄로 소개하면? 예: 영수증 사진으로 지출을 기록하는 가계부 앱
2. 담당 기능과 마일스톤: 맡은 기능 이름과, 기능별로 끝낸 일·남은 일을 알려 주세요.
   커밋이 많았던 폴더: src/payments(변경 42회), src/search(변경 17회)
   → 기본값: 위 폴더를 각각 하나의 기능으로 두고 마일스톤 없이 시작
3. 내 커밋 신원: 기본값 me@example.com. 다른 메일이나 이름으로도 커밋했다면 함께 적어 주세요.
4. 작업 단위: 스프린트 같은 반복 단위가 있나요?
   저장소에서 찾은 후보: 태그 sprint-* (12개) / 릴리스 태그 간격 약 14일
   → 기본값: 첫 번째 후보, 후보가 없으면 "없음"
5. Notion 위치: 기본값 개인페이지 / project / demo / 작업로그
   없으면 이 경로로 페이지를 새로 만듭니다.
6. 처음 기록할 범위: 기본값 최근 7일
```

- `preflight`에 `members`가 있으면 워크스페이스다. 질문 맨 위에 "묶을 저장소: <members>" 한 줄을 넣고, 2번 폴더 목록은 `저장소 폴더/경로` 그대로 보인다. 4번 작업 단위는 기간 방식만 묻는다.
- 2번 폴더 목록은 사용자에게만 보이는 설정 대화다. 기록 파일과 Notion에는 기능 라벨만 들어간다.
- 감지한 작업 단위는 근거(태그 개수, 브랜치 이름 규칙, 릴리스 간격)를 짧게 함께 보인다.
- 답을 받은 뒤 추가 질문으로 이어 가지 않는다. 모호한 답은 합리적으로 정하고 마지막 보고에 적는다.

## 2. 답을 파일로 옮기기

1. `log-part/profile.md` — [profile](profile.md) 서식. 기능 라벨은 한국어 기능명으로 정하고, 폴더 경로는 `경로`에만 둔다.
2. `log-part/notion-template.md` — [notion-template](notion-template.md)을 그대로 복사한다. 사용자가 이후 이 사본을 고치면 그 사본을 따른다.
3. `log-part/notion.md` — [notion](notion.md) 서식으로 위치와 구조를 적는다. 페이지 ID는 3단계 뒤에 채운다.
4. `tasklog.py profile`로 서식을 확인한다. `label_warnings`가 있으면 라벨을 고친다.

## 3. Notion 페이지 만들기

Notion MCP 도구가 있을 때만 한다. 없으면 로컬 파일만 만들고 보고서에 `승인 시 진행: Notion 페이지 생성`으로 남긴다.

1. [notion](notion.md)의 "위치 확정" 순서대로 루트(개인페이지) → `project` → 프로젝트 페이지 → 작업로그를 찾거나 만든다. 같은 제목이 둘 이상이면 멈추고 사용자에게 고르게 한다.
2. 작업로그 아래에 `진행 현황` 페이지를 만든다. 서식은 notion-template의 "진행 현황 페이지".
3. 만든 페이지마다 `tasklog.py notion-set --kind root|container|project|log|progress --id <ID> --url <URL> --title <제목>`으로 state.json에 적고, notion.md의 표에도 같은 값을 적는다.
4. 페이지를 만들고 응답을 받지 못했으면 다시 만들지 않는다. 같은 제목으로 검색하고 내용을 확인한 뒤 그 페이지를 쓴다.

## 4. `설정`으로 다시 들어왔을 때

- 지금 profile.md와 notion.md의 값을 기본값으로 삼아 같은 질문을 보낸다.
- 바뀐 항목만 고친다. 마일스톤 체크도 여기서 받는다.
- Notion 위치를 바꾸면 새 위치를 3단계 순서로 확정하고 notion.md와 state.json을 함께 고친다. 예전 페이지는 지우거나 옮기지 않는다.
