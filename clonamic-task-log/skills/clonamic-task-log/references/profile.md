# profile.md 서식

첫 실행 설정의 답으로 `<프로젝트>/<에이전트 폴더>/log-part/profile.md`를 이 서식대로 만든다. 스크립트가 `- 키: 값` 줄과 `## 기능` 아래 구조를 읽으므로 키 이름은 바꾸지 않는다. 값이 없으면 `없음`이라고 쓰거나 줄을 뺀다.

```text
# 작업 프로필

이 파일은 /clonamic-task-log 가 읽습니다. 키 이름과 `## 기능` 아래 형식만 지키면 직접 고쳐도 됩니다.

- 파트: 백엔드 개발
- 신원: me@example.com, 12345+me@users.noreply.github.com, 내 이름
- 범위: 없음
- 제외 경로: 없음
- 작업 단위: 스프린트
- 작업 단위 기준: 기간 14일, 2026-09-28 시작
- 시간대: Asia/Seoul
- 첫 기록 범위: 7일
- 최대 커밋: 200
- 최대 파일: 2000
- 공개 용어: 없음
- 비공개 용어: 없음
- 내부 용어: 없음

## 기능

### 결제 모듈
- 경로: src/payments, tests/payments
- 키: payments, pay
- 마일스톤:
  - [x] 결제 요청 API
  - [ ] 환불 처리
  - [ ] 정산 리포트
```

## 키 설명

| 키 | 뜻 | 기본값 |
|---|---|---|
| 파트 | 프로젝트에서 맡은 역할 | 없음(묻는다) |
| 신원 | "내 작업"으로 셀 커밋 작성자. 메일 또는 이름, 쉼표로 구분 | 현재 `git config user.email` |
| 범위 | 이 경로 안의 변경만 센다(모노레포에서 내 패키지만 볼 때) | 없음(전체) |
| 제외 경로 | 이 경로의 변경은 세지 않는다(예제 복제본, 실험 폴더) | 없음 |
| 작업 단위 | 스프린트·마일스톤 같은 반복 단위 이름. 없으면 `없음` | 자동 감지 결과 |
| 작업 단위 기준 | `기간 14일, 2026-09-28 시작` / `태그 sprint-*` / `브랜치 sprint-*` | 자동 감지 결과 |
| 시간대 | 날짜 경계 | Asia/Seoul |
| 첫 기록 범위 | 처음 실행할 때 거슬러 볼 날 수 | 7일 |
| 최대 커밋, 최대 파일 | 한 번에 모을 상한. 넘으면 최신부터 담고 "일부만 수집"으로 표시 | 200, 2000 |
| 공개 용어 | 게이트가 막지 않을 고유명사(예: 사내가 아닌 공개 제품명 `FastAPI`) | 없음 |
| 비공개 용어 | 기록에 절대 나오면 안 되는 말(고객사, 내부 코드명) | 없음 |
| 내부 용어 | 프로젝트 안에서만 통하는 말. 쉼표로 구분하며, 기록에 나오면 게이트가 막아 바깥 사람이 읽어도 알 수 있는 말로 풀어 쓰게 한다 | 없음(전역 기본값 없음) |

## 기능 항목

- `### 이름`이 기록에 쓰는 기능 라벨이다. 파일 이름이나 경로가 아닌 한국어 기능명으로 쓴다(예: "결제 모듈", "검색 개선").
- `경로`: 이 기능에 속한 폴더. 진행률 계산과 커밋-기능 연결에 쓴다. 기록에는 나오지 않는다.
- `키`: 커밋 메시지의 범위 표기(`feat(payments): …`의 `payments`)와 연결할 이름. 선택.
- `마일스톤`: `[x]` 끝남, `[ ]` 남음. 진행률의 가장 큰 근거다. 끝낸 마일스톤은 사용자가 직접 `[x]`로 바꾸거나 `설정`으로 알려 준다.

### 내부 용어 예시

이 플러그인 자신의 기록을 쓰는 프로젝트라면 `- 내부 용어: 게이트, 작업 메모, 지문, 프리플라이트, 리더, 작성자`처럼 적어 둘 수 있다. 값은 프로젝트마다 다르고 플러그인이 기본으로 넣어 주지 않는다.

## 진행률 추정식 (모든 값은 추정)

- 마일스톤이 있으면: 70×(끝낸 비율) + 10×활동 + 10×테스트 + 10×미완 표시 적음. 모두 끝나기 전에는 95% 이하, 모두 끝나면 90% 이상.
- 마일스톤이 없으면: 35×코드 있음 + 25×활동 + 15×테스트 + 10×미완 표시 적음. 최대 85%.
- 활동 = min(1, 그 경로를 바꾼 내 커밋 수 ÷ 10), 테스트 = 경로 안에 테스트 파일이 있음, 미완 표시 적음 = 1 − min(1, TODO·FIXME·미구현 표시 수 ÷ 10). 5% 단위로 반올림한다.
- 경로가 없는 기능은 90×(끝낸 비율) + 10×활동이다.
- 기록과 Notion에는 마일스톤이 있는 기능의 진행률만 `약 n%`로 나온다. 마일스톤이 없는 기능은 `마일스톤 미설정`이고, 경로가 저장소에서 사라진 기능은 진행 출력에서 빠진다.
