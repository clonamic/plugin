# clonamic-AI-HTML-PPT
- 편의를 위해 아래 내용의 Ai는 claude code, codex, grok build, cursor 같은 에이전트 도구를 의미한다.

## 핵심 요약

- 주 목적은 무료 PPT 편집기다. MS Office PowerPoint를 대신하는 로컬 HTML 편집기로, 슬라이드와 문서(A4 등)를 만든다.
- 자유도는 Figma만큼 높다. 이를 위해 Figma 데스크톱 앱을 리버스 엔지니어링해 도형, 효과, 레이아웃, 편의 기능의 동작을 그대로 옮겼다.
- 이미지는 끌어 놓기, 붙여넣기, 파일 선택으로 넣는다. AI는 파일 경로만 받아도 넣는다.
- 명령은 `/clonamic-ai-html-ppt [덱 이름 또는 만들고 싶은 것]` 하나다. 사용자가 직접 입력했을 때만 실행된다.
- 사용자는 Figma와 같은 캔버스에서 직접 고친다. 사용자가 쓰던 AI는 같은 덱을 요소 하나씩 직접 고친다. 바뀐 내용은 열린 탭에 바로 보인다.
- 어떤 페이지든 캔버스에서 본 그대로 PDF로 내보낸다. 받은 PDF는 따로 손보지 않고 바로 발표, 인쇄, 공유에 쓴다.

## 기능
- 피그마 캔버스의 기능들이 담긴 캔버스에서 직접 수정이 가능하지만, 사용자가 쓰고있는 AI를 사용해 네이티브로 수정 가능하다. 

## 문제점
1. 피그마 AI는 성능이 별로이다. 
2. 사용자가 사용하던 AI를 Figma MCP로 작업하면, 불필요한 토큰낭비와 작업이 느리다. 그리고 수정할때마다 덮어쓰는등 네이티브 작업이 아니라는 느낌이 직관적으로 든다. 

## 철학

1. **무료 PPT 편집기, 자유도는 Figma.** 목적은 돈을 내지 않고 쓰는 PPT 편집기다. 다만 틀에 갇힌 PPT가 아니라 Figma처럼 무엇이든 원하는 자리에 원하는 모양으로 놓을 수 있어야 한다. 그래서 Figma를 리버스 엔지니어링했다. 이미지, 도형, 텍스트, 효과를 자유롭게 쓰고, 단축키와 스마트 가이드 같은 편의 기능도 Figma와 같게 쓴다.
2. **Figma 위에 완전히 맞물린 AI.** AI를 옆에 붙이지 않고 편집기의 일부로 만든다. 사람과 AI는 같은 데이터를 같은 단위(요소 하나)로 고친다. AI도 사람이 보는 화면을 이미지로 본다.
3. **덮어쓰지 않는다.** AI는 덱 전체를 다시 쓰지 않고, 바꿀 속성만 바꾼다. 사용자가 방금 고친 것은 AI가 건드리지 않는다. 같은 요소를 동시에 고치면 충돌로 알려 준다.
4. **보이는 그대로 나와서 바로 쓴다.** 사용자가 의도한 화면이 그대로 출력되어야 결과물을 바로 쓸 수 있다. 그래서 캔버스, 발표, PDF를 같은 렌더러 하나로 그린다. A4 페이지는 실제 A4 PDF가 되고, PDF의 글자는 선택하고 검색할 수 있다.
5. **사용자가 쓰던 AI를 그대로 쓴다.** 별도 AI 서비스나 API 키가 없다. 터미널에서 쓰던 Claude Code·Codex·Cursor·Grok이 그대로 편집기의 AI가 된다.
6. **가볍고 단단하게.** Python 표준 라이브러리, SQLite, 빌드 없는 HTML·CSS·JS만 쓴다. 로컬에서만 돌고, 탭을 모두 닫으면 스스로 꺼진다.

## 1. 사용 흐름

1. 사용자가 터미널의 AI에게 명령을 입력한다. 뒤에 만들고 싶은 것을 적으면(예: `신제품 발표 10장`, `A4 세로 보고서`) 그 말이 첫 요청이 된다.
2. AI가 로컬 편집기를 열고 연결한다. 오른쪽 사이드바에 `연결됨 · Claude Code`가 보인다.
3. 사용자는 캔버스에서 직접 만들고 고친다. AI에게 맡길 때는 세 가지 방법이 있다.
   - **AI 탭 채팅**: 페이지 전체 요청. 빠른 요청 칩(이 페이지 다듬기, 정렬 맞추기, 맞춤법 확인 등)도 쓸 수 있다.
   - **인라인 수정(⌘J)**: 요소를 고르고 한 줄로 요청한다. 고른 요소만 바뀐다.
   - **포커스 핀(⌘⇧J)**: 문제가 있는 요소나 영역에 번호 핀과 메모를 남기고 AI에게 보낸다.
4. AI가 바꾼 내용은 바로 보이고, 알림의 `되돌리기` 한 번으로 그 요청 전체를 되돌린다.
5. 내보내기에서 현재 페이지, 고른 페이지, 페이지마다 따로, 전체 한 파일 중 하나를 골라 PDF로 저장한다.
6. 브라우저 탭을 모두 닫거나 AI에게 닫으라고 하면 편집기가 꺼진다. 다음에 같은 명령으로 이어서 연다.

## 2. 편집기

| 위치 | 내용 |
|---|---|
| 위 | 덱 메뉴(목록·새 덱·이름 바꾸기·삭제), 저장 상태, 확대 비율, 발표, 내보내기 |
| 왼쪽 | `프레젠테이션`(주제별 덱 목록, 최근 수정 순. 누르면 열기, 새로 만들기, 이름 바꾸기, 삭제, 접기) / 그 아래 `페이지`(썸네일, 추가·복제·삭제·순서 바꾸기) / `레이어`(트리, 이름 바꾸기, 숨김·잠금, 끌어서 순서·부모 바꾸기) |
| 가운데 | 무한 캔버스. 아래쪽 도구 막대에 선택, 프레임, 도형, 펜, 텍스트, 표, 손, 포커스 핀 |
| 오른쪽 | `AI`(연결 상태, 진행 단계, 채팅, 확인 카드, 핀 목록, 실행 기록) / `디자인`(선택한 요소의 모든 속성) |

**만들 수 있는 것**

- 도형: 사각형(모서리 개별 반경·스무딩), 선, 화살표(끝 모양 8종), 타원(호·도넛), 다각형·별(꼭짓점 3~60), 펜(베지어), 연필, 이미지, 비디오, 텍스트, 표, 프레임, 섹션
- 이미지: ⌘⇧K로 파일 고르기, 캔버스에 끌어 놓기, ⌘V 붙여넣기. PNG·JPEG·GIF·WebP 이미지와 MP4·WebM 비디오. AI는 `ppt.py asset 파일`로 넣는다.
- 도형 연산: 불리언(합치기·빼기·교차·제외, 원본 유지), 평탄화, 획 윤곽선
- 칠: 단색, 선형·방사형·각도·다이아몬드 그라디언트, 이미지(채우기·맞추기·자르기·바둑판, 필터 7종). 여러 겹을 쌓을 수 있다.
- 획: 안쪽·가운데·바깥쪽, 변마다 다른 두께, 대시, 끝 모양, 꺾임 모양
- 효과: 드롭 섀도, 이너 섀도, 레이어 블러(균일·점진), 배경 블러, 블렌드 모드 19종, 불투명도
- 텍스트: 일부만 다른 서식, 링크(웹 주소·메일, 발표와 PDF에서 눌림), 글머리표·번호 목록, 자동 너비·자동 높이·고정·말줄임, 행간·자간·문단 간격, 한국어 단어 단위 줄바꿈
- 레이아웃: 오토 레이아웃(방향, 줄바꿈, 간격, 여백, 정렬, Hug·Fill·Fixed), 제약, 레이아웃 가이드
- 페이지 규격: 프레젠테이션 16:9·4:3, A3·A4·A5·A6, Letter·Legal·Tabloid, 사용자 지정. 가로·세로 전환
- 발표: 전체 화면 발표, 발표자 보기(다음 슬라이드, 발표자 노트, 타이머)

**편의 기능**

- Figma와 같은 단축키: 도구(V, F, R, O, L, ⇧L, P, ⇧P, T, H, K), 그룹 ⌘G, 복제 ⌘D, 정렬 ⌥A/D/W/S/H/V, 순서 ⌘]/⌘[, 불리언 ⌥⇧U/S/I/E, 오토 레이아웃 ⇧A 등. 전체 목록은 ⌃⇧?에서 볼 수 있다.
- 스마트 가이드와 간격 표시, ⌥ 거리 측정, 눈금자, 픽셀 그리드
- Figma식 선택: 더블클릭으로 한 단계 안, ⌘클릭으로 깊은 선택, Tab으로 형제 이동
- 숫자 칸에 수식 입력, 끌어서 값 바꾸기
- 속성 복사·붙여넣기, 같은 속성 모두 선택, 일괄 이름 바꾸기
- ⌘K 동작 찾기, 오른쪽 클릭 메뉴
- 되돌리기 100단계. AI가 바꾼 것도 포함된다.

## 3. AI 연동

AI 요청은 정해진 그래프를 따라 처리된다. 그래프는 LangGraph 방식이다(상태, 조건 연결, 체크포인트, 사람 확인).

```
이해(intake) → 계획(plan) → 적용(apply) → 검증(verify) → 답변(reply)
                 │              ▲             │
                 │              └─ 문제 있으면 다시 계획(최대 2번)
                 ├─ 질문이면 바로 답변
                 ├─ PDF 요청이면 내보내기 → 답변
                 └─ 큰 삭제면 사용자 확인 카드 → 적용 또는 취소
```

- **이해·적용·검증·내보내기**는 편집기 코드가 처리한다. **계획·답변**은 사용자의 AI가 맡는다.
- **이해** 단계는 AI에게 다음을 넘긴다: 보고 있는 페이지, 고른 요소, 포커스 핀, 그 영역의 화면 이미지.
- **검증** 단계는 다음을 검사하고, 바뀐 화면 이미지를 AI에게 다시 보여 준다:
  - 페이지 밖으로 나간 요소
  - 텍스트 넘침
  - 글자와 배경의 대비
  - 너무 작은 글자
  - 겹침
  - 미세하게 어긋난 정렬
- 터미널에서 직접 고친 덱도 `ppt.py check`로 같은 검증(측정, 자동 크기 기록, 검사)을 받는다. 웹에서 "전체 점검"처럼 고칠 것 없이 요청하면 지정한 페이지를 모두 검사한다.
- **인라인 수정**의 범위는 코드가 강제한다. 고른 요소 밖을 바꾸는 작업은 거부된다.
- 그래프는 단계마다 저장된다. 편집기가 다시 켜져도 하던 요청을 이어서 처리한다.

## 4. 필요한 것

- Python 3.12 이상. 표준 라이브러리만 쓴다.
- PDF 내보내기와 AI의 화면 보기: 설치된 Chrome, Chromium, Edge 중 하나. 없으면 PDF는 브라우저 인쇄 창으로 대신하고, 화면 보기는 건너뛴다.
- 알려진 제약: Chrome이 PDF에 글꼴을 Type 3 글리프로 넣는다. 글자 선택, 검색, 복사는 되지만 일부 뷰어에서 크게 확대하면 글자가 흐리게 보일 수 있다.
- 데이터는 `~/.clonamic/ai-html-ppt/`에 둔다. 사용자 저장소에는 아무것도 쓰지 않는다.

## 5. 범위 밖

- PPTX 가져오기·내보내기, PNG·SVG 내보내기, 차트
- 컴포넌트·변수·스타일 라이브러리, 프로토타입, 댓글, 여러 사람 동시 편집
- Figma 파일 가져오기, Figma 코드·아이콘·폰트 사용. 동작만 같고 구현은 새로 만들었다.
