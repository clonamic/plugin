# fde-mode

고객 인터뷰부터 맞춤 에이전트 서비스 제작과 배포까지 Claude Code 안에서 현장 배치 엔지니어(FDE) 조직처럼 진행하는 플러그인이다.

## 왜 만들었나

혼자 인터뷰하면서 서비스까지 만들면 무너지는 곳이 비슷하다. 물어야 할 것을 놓치고, 고객에게 물을 일과 내가 정할 일이 섞이고, 묻다가 만들 시간이 모자란다. 이 일을 여러 전문가가 나눠 맡는 조직처럼 진행하려고 만들었다.

## 기능

- 인터뷰 분석: 대화를 붙여넣으면 서로 다른 관점으로 분석해 빈틈을 찾는다.
- 질문 카드: 고객에게 할 질문을 확신도, 근거 발언과 함께 정리한다.
- 결정 분리: 내가 정할 일은 따로 등급을 매겨 선택지로 묻는다.
- 구현과 배포: 기술을 고르고 범위를 확정한 뒤 조각 단위로 설계, 구현, 배포한다.
- 품질 점검: 독립 리뷰와 QA로 대화 품질과 동작을 확인한다.
- 대시보드: 진행 상황을 로컬 웹 화면에서 본다.

## 장점

- 토론 기록을 보지 않는 별도 검증으로 억지 질문을 걸러 낸다.
- 구현 중에도 설계와 진행 방향을 선택지와 추천으로 물어보고, 결정은 내가 한다.
- 인프라 삭제, 비밀 값 출력, 강제 푸시는 안전 장치가 막는다.
- 프로젝트별로 기록을 나눠 저장해서 세션을 다시 열어도 이어진다.

## 사용법

Claude Code 전용이다.

- Claude Code: `/plugin marketplace add clonamic/plugin` 후 `/plugin install fde-mode@clonamic`

명령 하나로 켜고 끈다. 켠 뒤에는 인터뷰 대화를 붙여넣고, 물어보는 선택지에 답하면 된다.

```text
/fde-mode
/fde-mode off
```
