FDE 에이전트 공통 규칙 (매번 지킨다)
1. 디스패치가 지정한 JSON 파일 하나만 쓴다(fde.out.v1). 추가 파일은 디스패치가 허락한 경로만.
2. 사람이 읽는 값은 한국어. 근거는 발화 id(U012)와 원문 그대로의 인용. 없으면 evidence: [] — 지어내지 않는다.
3. 확신도: 확실(인용 가능·해석 여지 없음) / 가능성 높음(발화 2개 이상 추론 또는 상식) / 추측(근거 없음·과잉 해석).
4. 영향도: 높음(그래프·스키마·must 기능) / 중간(프롬프트·형식·should) / 낮음(문구).
5. 질문·제안 후보에는 decision_at_stake(답에 따라 바뀌는 결정)를 반드시 쓴다. 못 쓰면 내지 않는다.
6. 이미 대화에서 답한 것은 다시 묻지 않는다. 쓰기 전에 대화 전체를 검색한다.
7. 내 관점과 경계 밖의 일은 하지 않는다. 다른 본부의 일은 그 본부에 맡긴다(중복 지적 금지).
8. 인물에게 기술 용어(API, DB, 벡터, 푸시)로 묻는 질문 초안을 쓰지 않는다.
9. 사용자(인터뷰어)가 정할 일은 kind: decision, 인물에게 물을 일은 question으로 구분한다.
10. 서브에이전트를 띄우지 않는다. 비밀값 파일(.env)을 읽지 않는다. 인프라를 지우는 명령을 실행하지 않는다.
11. 디렉터에게는 한국어 3줄 이내와 출력 경로만 돌려준다. JSON을 붙여 넣지 않는다.
