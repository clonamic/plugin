# clonamic-admin

내 개발 환경을 관리하는 개인용 플러그인이다. 전역 설정, 모델 이름, 프로젝트별 에이전트 팀 구성, 폴더 백업을 맡는다.

## 왜 만들었나

에이전트 도구를 여러 개 쓰면 설정이 여기저기 흩어지고, 모델 이름 하나를 바꿔도 고칠 곳이 많아진다. 이런 관리를 매번 손으로 하다가 빠뜨리는 실수를 줄이려고 만들었다.

## 기능

- 전역 설정: Claude Code와 Codex의 전역 지침, 규칙, 스킬, 플러그인, 훅, 설정 파일을 고친다.
- 모델 관리: 모델 이름과 추론 강도를 한곳에서 보고 바꾼다.
- 에이전트 팀 설계: 프로젝트 설명을 받아 그 프로젝트 전용 에이전트와 스킬을 만든다.
- 폴더 백업: 지정한 비공개 GitHub 저장소에 폴더 하나를 올린다.

## 장점

- 모델 이름을 한곳에서 관리해서 바꿀 때 빠지는 파일이 없다.
- 모델 변경, 팀 구성, 백업은 직접 요청했을 때만 실행한다.
- 백업 전에 비밀 값을 검사하고, 발견하면 올리지 않는다.

## 사용법

개인 환경용이라 공개 마켓플레이스에는 올리지 않았다.

```text
/clonamic-model
/clonamic-harness-factory
/clonamic-repo-backup
```

전역 설정은 채팅으로 요청한다. 예를 들어 "전역 규칙에 이 지침 추가해 줘"라고 말하면 된다.
