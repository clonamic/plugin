# clonamic-harness

AI 코딩 에이전트의 작업 순서를 잡아 주는 규칙 플러그인이다. 요청 해석, 승인, 실행, 증거 보고 순서를 지키게 한다.

## 왜 만들었나

에이전트에게 일을 맡기면 시키지 않은 일까지 하거나, 끝나지 않은 일을 끝났다고 말하거나, 사소한 일마다 "계속할까요?"라고 묻는 일이 잦다. 승인은 꼭 필요한 곳에서만 받고, 그 안에서는 끝까지 맡길 수 있게 하려고 만들었다.

## 기능

- 요청 해석: 요청을 항목별로 나누고, 시키지 않은 작업을 걸러 낸다.
- 승인: 바꾸기 전에 무엇을 어떻게 왜 바꾸는지 적은 명세서로 승인받는다. 승인은 작업당 최대 두 번이다.
- 팀 구성: 효과가 비용보다 클 때만 독립 검토자 같은 보조 에이전트를 쓴다.
- 마무리: 마지막 변경 뒤에 모든 항목을 다시 확인하고, 결론부터 쓴 보고서를 낸다.

## 장점

- 한 번 승인하면 범위 안에서는 다시 묻지 않고 끝까지 간다.
- 완료 보고에 새로 확인한 증거를 담는다.
- 사용자 환경과 프로젝트 파일을 승인 없이 바꾸지 않는다.

## 작업 흐름

| 단계 | 하는 일 |
|---|---|
| 이⁠해 | 요청을 항목별로 나누고, 지금 상황에 맞는 의도로 다시 쓴다. 시키지 않은 일과 과한 설계를 미리 걸러 낸다 (`clonamic-intake`) |
| 승⁠인 | 읽기는 자유, 쓰기는 승인 후. 요청이 애매하면 작업명세서, 바꾸기 전에는 개발명세서로 승인받는다(최대 두 번) (`clonamic-spec`) |
| 실⁠행 | 가장 작은 변경으로 진행하고, 승인한 범위 안에서는 고치고 다시 확인하는 반복을 묻지 않고 계속한다. 잘못되면 비용이 큰 일에만 독립 검토자(`clonamic-reviewer`)를 붙인다 (`clonamic-spec`, `clonamic-team`) |
| 마⁠무⁠리 | 마지막 변경 뒤 새 증거로 진짜 끝났는지 다시 확인하고, 아니면 끝까지 마친 뒤 결론부터 보고한다 (`clonamic-finish`) |

## 설계 원칙

- **사용자 지시가 1순위다.** 하네스는 지시를 막지 않고, 범위를 넘지 않게만 한다. AI의 성능을 떨어뜨리지 않도록 제한은 최소로 둔다.
- **읽기는 먼저, 많이.** 잘못 쓰는 것보다 읽는 비용이 적어서, 명세서를 쓰기 전에 현재 동작을 충분히 파악한다.
- **승인은 짧게.** 명세서 맨 위에 사용자의 프롬프트와 해석을 함께 보여 주고, `승인:코드` 한 줄로 승인한다.
- **오버엔지니어링을 막는다.** 불필요한 일 빼기, 기존 코드 재사용, 표준 기능 순으로 가장 작은 변경을 고른다.
- **사용자 환경을 바꾸지 않는다.** 범위 밖 변경과 되돌리지 않은 자동화를 가장 큰 실패로 본다.
- **확인하지 않은 것은 말하지 않는다.** 완료는 새 증거로만 판단하고, 확인 못 한 것은 미검증으로 따로 적는다.
- **보고는 두괄식 목록으로.** 결과와 실패를 먼저, 문단 대신 짧은 목록으로 쓴다.
- **도구가 바뀌어도 그대로.** 어떤 에이전트든 `AGENTS.md` 하나만 가리키면 같은 규칙이 적용된다.
- **에이전트는 필요할 때만 늘린다.** 혼자 처리를 기본으로, 효과가 비용보다 클 때만 작업자+검토자, 리드+전문가, 결정 검토로 팀을 꾸린다. 다른 에이전트 CLI(Claude, Grok, Hermes)에 일을 맡기는 것도 범위를 정해 한 번만 한다.

## 명세서

| 양식 | 쓰는 때 | 담는 내용 |
|---|---|---|
| 작업명세서 | 요청이 아직 애매할 때만 | 프롬프트와 해석, 요구, 방법, 이유, 산출, 완료, 제외 |
| 개발명세서 | 파일이나 코드를 바꾸기 전 | 변경, 이유, 영향, 검증, 복구 |

- 명세서는 채팅에만 쓰고 파일로 남기지 않는다. 끝에 `승인 대기 — … (승인:CODE)`가 붙고, `승인`이나 `승인:CODE`로 승인한다.
- 요청이 분명하면 개발명세서 하나로 끝나고, 질문이나 검토는 승인 없이 바로 처리한다.

## 사용법

- Claude Code: `/plugin marketplace add clonamic/plugin` 후 `/plugin install clonamic-harness@clonamic`
- Codex: `codex plugin marketplace add clonamic/plugin` 후 `codex plugin add clonamic-harness@clonamic`
- Grok: `grok plugin install https://github.com/clonamic/plugin#clonamic-harness --trust`

규칙을 항상 켜려면 이 폴더의 `AGENTS.md`를 `~/.clonamic/AGENTS.md`로 복사하고 도구에 연결한다.

- Claude Code: `~/.claude/CLAUDE.md`에 `@~/.clonamic/AGENTS.md`를 넣는다.
- Codex: `ln -s ~/.clonamic/AGENTS.md ~/.codex/AGENTS.md`
- Grok: `ln -s ~/.clonamic/AGENTS.md ~/.grok/AGENTS.md`

### 개인 지침 추가

개인 지침은 `AGENTS.md`에 넣지 않고 따로 적는다. 파일이 있으면 읽고, 없으면 건너뛴다.

- Claude Code: `~/.clonamic/claude_add.md`
- 그 밖의 도구: `~/.clonamic/agent_add.md`

내용이 같으면 심볼릭 링크로 연결한다.

```bash
ln -s ~/.clonamic/agent_add.md ~/.clonamic/claude_add.md
```
