# clonamic-korean

명령은 `/clonamic-korean` 하나다.

번역문처럼 읽히는 한글은 문장 뼈대가 영어를 따라가서 생긴다. 탐지된 구간만 고치고, 손대지 않은 문장은 그대로 둔다.

사실을 바꾸면 다른 글이 된다. 수치, 고유명사, 직접 인용, 서법, 문체 높낮이는 유지한다.

많이 고칠수록 자연스럽지 않다. 글자 변경률 30%는 경고하고, 50%가 넘으면 그 결과를 쓰지 않는다.

사람이 더 쓰는 표현을 기계적으로 지우면 오히려 티가 난다. 그 신호는 규칙으로 두지 않는다. 가벼운 글까지 전부 고치면 과하다. 먼저 손볼 양을 보고, 한 단계로 끝낼지 이어서 고칠지 정한다.
