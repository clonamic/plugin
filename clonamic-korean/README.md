# clonamic-korean

명령은 `/clonamic-korean` 하나다. 이력서, 포트폴리오, 보고서, 게시글, 기술 문서의 한국어를 새로 쓰거나 다듬는다.

명령 뒤에 하고 싶은 일을 말로 적는다. `가볍게`, `깊게`, `진단만`, `써줘`, `내 문체로`, `쉽게`, `이야기처럼`, `첫 문장`처럼 적으면 그에 맞춰 움직인다. 아무것도 적지 않으면 걸린 곳만 다듬는다.

번역문처럼 읽히는 한글은 문장 뼈대가 영어를 따라가서 생긴다. 걸린 구간만 고치고, 손대지 않은 문장은 그대로 둔다.

사실을 바꾸면 다른 글이 된다. 숫자, 고유명사, 직접 인용, 서법, 문체 높낮이는 유지한다. 원문에 없는 숫자, 과장, 외래어 업무 용어, 명사 사슬을 새로 만들지 않는다.

많이 고칠수록 자연스럽지 않다. 다듬기에서 글자 변경률 30%는 경고하고, 50%가 넘으면 그 결과를 쓰지 않는다. 원문과 결과의 대조는 스킬 폴더의 작은 검사기가 맡는다.

스킬 폴더 하나(SKILL.md, references, scripts)만으로 동작한다. 특정 에이전트 도구에 기대지 않는다.
