# 경로

사용자 말이 우선이다.

- `정밀`, `제대로`, `꼼꼼히`는 정밀로 고정한다.
- `가볍게`, `빠르게`는 가볍게 고정한다.
- 말이 없으면 정찰 결과로 정한다. 신호 0~2개는 가볍게, 3~4개는 보통, 5~6개이거나 검증을 남기라는 요청이면 정밀이다.
- 글 길이만으로 경로를 올리지 않는다.

가볍게는 정찰에서 끝난 수 있다. 보통은 탐지 뒤 겨냥해서 고친다. 정밀은 고친 뒤 한 번 더 보고 경계 스크립트를 돌린다.

한 단계로 충분한지, 이어서 갈지는 매 단계 끝에서 다시 본다. 잘 쓴 글을 정밀로 밀지 않는다.
