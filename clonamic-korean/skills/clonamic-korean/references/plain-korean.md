# 쉽게 풀어 쓰기

글이 빽빽해서 한 번에 읽히지 않을 때 쓴다. 안내문, 설명 글, 기술·금융·제도처럼 추상적인 주제에서 효과가 크다. 이미 입말에 가까운 짧은 글에는 쓰지 않는다.

## 무엇을 쉽게 하나

쉽게 쓴다는 것은 내용을 덜어 내는 일이 아니다. 읽는 사람이 문장을 해석하느라 쓰는 힘을 줄이는 일이다. 생각은 깊어도 되고, 문장이 그 깊이를 가로막지 않으면 된다.

한국어 글을 무겁게 만드는 것은 대개 네 가지다.

1. **한자어 서술어.** `제고하다`, `도모하다`, `상이하다`, `용이하다`처럼 입으로는 잘 안 쓰는 말.
2. **명사로 굳힌 동작.** `점검을 실시했다`, `개선을 진행했다`, `검토를 수행했다`.
3. **겹친 관형절.** 명사 하나 앞에 꾸밈 절이 둘 셋 쌓인 문장.
4. **풀지 않은 전문어.** 독자가 모르는 용어나 약어가 설명 없이 나오는 것.

기준은 이렇다. 그 분야를 모르는 똑똑한 동료가 한 번 읽고 따라올 수 있는가. 그러면서도 가르치려 든다고 느끼지 않는가.

## 고치는 법

- **입으로 하는 말로.** 동료에게 말로 설명한다면 어떤 낱말을 쓸지 떠올린다.

  | 무거운 말 | 쉬운 말 |
  |---|---|
  | 제고하다 | 높이다 |
  | 도모하다 | 꾀하다, (구체 동사) |
  | 상이하다 | 다르다 |
  | 용이하다 | 쉽다 |
  | 기인하다 | ~ 때문이다 |
  | 수반하다 | 따르다, 함께 생기다 |
  | 초래하다, 야기하다 | 일으키다, 낳다 |
  | 규명하다 | 밝히다 |
  | 상존하다 | 늘 있다 |
  | 활용하다 | 쓰다 |
  | 요구되다 | 필요하다 |

  업계에서 실제로 쓰는 용어(구현, 배포, 정산)는 바꾸지 않는다.

- **동작은 동사로.** `점검을 실시했다` → `점검했다`, `개선을 진행했다` → `고쳤다`. `실시`, `진행`, `수행`, `시행`이 붙으면 덜어 낼 수 있는지 본다.
- **한 문장에 한 생각.** 관형절이 겹치거나 `~하고, ~하며, ~해서`가 길게 이어지면 나눈다. 꾸밈 절이 긴 명사는 그 명사를 먼저 말하고 설명을 뒤 문장으로 보낸다.
- **모르는 말은 처음 한 번 푼다.** 독자가 함께 쓰는 전문어는 그대로 둔다. 개발자에게 API를 풀어 줄 필요는 없지만, 일반 사용자 안내문에서는 한 번 풀어 준다.
- **주어를 세운다.** `요청이 접수되면 처리가 진행됩니다` → `요청을 받으면 담당자가 처리합니다`. 행위자가 원문에 없으면 만들지 않는다.
- **구체적인 것으로.** `관련 기능`보다 `내보내기 버튼`, `효율 향상`보다 원문에 있는 실제 결과.
- **부정을 긍정으로.** `해당하지 않는 경우를 제외하고는` → `해당하면`. 다만 부정이나 예외 자체가 요건이면 그대로 둔다.
- **예시 하나.** 정의를 길게 늘이는 것보다 실제 장면 하나가 빨리 이해된다. 예시는 원문이나 사용자 자료에서 가져오고, 만든 예시는 예시라고 밝힌다.
- 공지와 안내문의 굳은 서식 말투(`상기`, `익일`, `의거하여`)는 [norms](norms.md)의 표를 본다.

## 다른 기준과 부딪치지 않게

- **리듬.** 낱말을 쉽게 한다고 문장을 전부 짧게 자르지 않는다. 쉬운 낱말로 된 긴 문장은 한숨에 읽힌다. 짧은 문장만 늘어놓으면 오히려 기계가 쓴 글처럼 들린다.
- **구체성.** 숫자, 이름, 사례는 글을 쉽게 만든다. 쉽게 쓴다는 이유로 지우지 않는다.
- **목소리.** 필자의 말버릇과 입말은 남기고 그 주변의 복잡함만 걷는다.
- **사실.** 풀어 쓰다 뜻이 넓어지거나 좁아지지 않게 한다. 조건과 유보는 그대로 둔다.

## 무게 가늠

- 소리 내어 읽는다. 숨이 차거나 다시 읽게 되는 문장이 무거운 문장이다.
- 한 문장이 60자를 훌쩍 넘고 관형절이 둘 이상 겹치면 나눌 후보다.
- 한 문단에 `-적`, `-성`, `-화`와 한자어 서술어가 몰려 있으면 표시한다.
- 풀이 없이 나온 낯선 용어와 약어를 표시한다.

## 진단 형식

진단만 요청받았으면 걸린 문장을 그대로 인용하고 고친 안을 붙인다.

```text
쉽게 풀기 진단
- 한자어 서술어: "서비스 접근성 제고를 도모하고자 합니다" → "서비스를 더 쉽게 쓰도록 하려고 합니다"
- 명사로 굳힌 동작: "전수 점검을 실시하였습니다" → "전부 점검했습니다"
- 겹친 관형절: "지난주 배포된 결제 모듈에서 발생한 오류로 인해 지연된 정산"
  → "지난주 배포한 결제 모듈에서 오류가 났다. 그 때문에 정산이 늦어졌다."
- 풀지 않은 약어: "SLA 기준" → 처음 한 번 "서비스 수준 약속(SLA)"
```
