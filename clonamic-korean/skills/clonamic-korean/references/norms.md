# 규범, 표기, 높임

AI 티와 별개로 글을 어색하게 만드는 규범 문제를 다룬다. 다듬기와 새로 쓰기의 마지막 점검에 쓰고, 인자에 `맞춤법`, `띄어쓰기`, `표기 맞춰`, `글자 수`가 있으면 이 파일을 먼저 본다.

## 원칙

- **정답이 하나인 것만 바로 고친다.** 뜻이나 문맥을 봐야 정해지는 것은 문맥을 확인하고, 확신이 서지 않으면 고치지 않고 결과 끝에 표시한다.
- **고유명사와 브랜드 표기는 규범보다 앞선다.** 회사, 제품, 서비스 이름이 비표준 표기를 쓰면 그대로 둔다.
- **필자가 일부러 쓴 말투는 오류가 아니다.** 블로그의 구어 표기, 대사 속 사투리, 의도한 줄임말은 둔다.
- **규범을 이유로 문체를 바꾸지 않는다.** 띄어쓰기 하나 고치면서 문장을 새로 쓰지 않는다.
- **틀린 표기를 일부러 섞지 않는다.** 사람 글처럼 보이려고 오타나 띄어쓰기 오류를 넣는 것은 이 스킬의 일이 아니다.

## 맞춤법

틀린 꼴이 한 가지로만 고쳐지는 것들이다. 검사기는 아래 왼쪽 표기를 `spelling`으로 알린다.

| 틀린 꼴 | 바른 꼴 | 알아보는 법 |
|---|---|---|
| 됬다, 되요, 되서, 안되요 | 됐다, 돼요, 돼서, 안 돼요 | `되어`로 늘려 말이 되면 `돼` |
| 뵈요 | 봬요 | `뵈어요`의 준말 |
| 않되다 | 안 되다 | 부정 부사 `안`은 띄운다 |
| 몇일 | 며칠 | 언제나 `며칠` |
| 역활 | 역할 | |
| 할께, 갈께, 드릴께 | 할게, 갈게, 드릴게 | 어미 `-ㄹ게`는 된소리로 적지 않는다 |
| 할려고, 갈려고 | 하려고, 가려고 | 어간에 `ㄹ`이 없으면 `-려고` |
| 어떻해 | 어떡해 / 어떻게 해 | |
| 웬지, 왠일, 왠만하면 | 왠지, 웬일, 웬만하면 | `왜인지`만 `왠지` |
| 오랫만 | 오랜만 | |
| 일일히, 깨끗히, 틈틈히 | 일일이, 깨끗이, 틈틈이 | 끝소리가 `이`로만 나면 `-이` |
| 컨텐츠, 메세지, 캡쳐 | 콘텐츠, 메시지, 캡처 | 외래어 표기법 |
| 리더쉽, 스케쥴 | 리더십, 스케줄 | |

문맥을 봐야 하는 것은 이렇게 가린다.

- `-예요`/`-이에요`: 받침 없는 명사 뒤에는 `예요`(서버예요), 받침 있는 명사 뒤에는 `이에요`(모델이에요). `아니에요`는 늘 `에요`다. `학교에요`처럼 조사 `에`에 `요`가 붙은 말은 맞을 수 있다.
- `-로서`(자격: 리더로서)와 `-로써`(수단: 대화로써).
- `결제`(돈을 냄)와 `결재`(승인), `지양`(피함)과 `지향`(추구), `맞히다`(정답)와 `맞추다`(맞대어 봄), `늘리다`(수와 양)와 `늘이다`(길이).
- `안`(부사, 띄움)과 `않-`(용언, `-지 않다`).

## 띄어쓰기

- 의존명사는 띄운다: `할 수 있다`, `만든 지 3년`, `쓸 데가 없다`, `본 대로`, `할 만큼`. 같은 꼴이 조사나 어미로 쓰이면 붙인다: `너뿐`, `규칙대로`, `만들었는지`, `바쁜데`.
- `-하다`, `-되다`가 붙은 동사는 한 단어다: `개발했다`, `적용됐다`. `개발 했다`처럼 띄우지 않는다. 다만 목적격 조사가 들어가면 띄운다: `개발을 했다`.
- 성과 이름은 붙이고 호칭과 직함은 띄운다: `김민수 씨`, `박지은 팀장`.
- 단위 명사는 띄우는 것이 원칙이고, 아라비아 숫자 뒤에서는 붙여도 된다: `세 개`, `3개`. 문서 안에서 한 방식으로 맞춘다.
- 보조 용언은 띄우는 것이 원칙이고 붙이는 것도 허용된다: `해 보다`/`해보다`. 필자가 고른 쪽을 따르고 섞였으면 많이 쓴 쪽으로 맞춘다.
- `안 되다`(금지, 불가능)와 `안되다`(안쓰럽다, 잘 풀리지 않다)는 뜻이 다르다.

## 문장 부호

- **쉼표**는 같은 자격의 말을 늘어놓을 때와 문장 성분을 분명히 끊어야 할 때 쓴다. 연결어미와 접속 부사(`그러나`, `따라서`) 뒤에 버릇처럼 찍지 않는다.
- **가운뎃점**은 짝을 이루는 말을 묶는다: `상·하반기`, `설계·구현`. 쉼표와 섞어 쓰면 묶음과 나열이 구분되게 쓴다.
- **쌍점**은 표제 뒤에 설명을 붙일 때 쓴다: `일시: 10월 5일`. 앞말에 붙이고 뒤는 띄운다. 시와 분(`14:30`), 비율(`2:1`)은 앞뒤를 붙인다. 본문 문장 중간에 영어처럼 쓰지 않는다.
- **물결표**는 기간과 범위에 쓰고 앞뒤를 붙인다: `3~5월`, `10~20%`. 붙임표(`-`)를 쓰는 문서라면 한 가지로 맞춘다.
- **따옴표**: 직접 인용과 대화는 큰따옴표, 마음속 말과 짧은 강조는 작은따옴표. 문서 안에서 곧은 따옴표(`"`)와 둥근 따옴표(`“”`) 중 하나로 맞춘다. 책과 신문 이름은 겹낫표나 큰따옴표, 글과 작품 이름은 홑낫표나 작은따옴표로 쓰고 문서 안에서 맞춘다.
- **괄호**: 외국어 원어는 처음 한 번만 붙인다. 괄호 안에 문장을 통째로 넣지 않는다.
- **줄표**는 문서에 한두 번이면 충분하다. 자주 보이면 쉼표나 별도 문장으로 바꾼다.
- **줄임표**는 `……`나 `...` 중 하나로 맞춘다.
- **목록과 제목 끝 마침표**는 문서 안에서 한 방식으로 맞춘다. 명사로 끝나는 항목에는 보통 찍지 않고, 문장으로 끝나는 항목에는 찍는다.
- 느낌표는 업무 글에서 거의 쓰지 않는다.

## 높임

- **등급 하나.** 같은 화자가 같은 독자에게 쓰는 본문은 합쇼체, 해요체, 한다체 중 하나로 맞춘다. 섞였으면 많이 쓴 쪽을 따른다. 인용, 대사, 화면 문구는 따로 본다. 합쇼체 본문 사이에 해요체를 가끔 섞어 부드럽게 하는 것은 필자의 선택일 수 있으니 의도가 보이면 둔다.
- **사물은 높이지 않는다.** `-시-`는 사람에게 붙는다.
  - `요청하신 자료가 준비되셨습니다` → `요청하신 자료를 준비했습니다`
  - `이 요금제는 무료이십니다` → `이 요금제는 무료입니다`
  - 높일 사람의 몸, 소유물, 생각, 말은 사람과 이어져 있으니 높인다: `대표님 말씀이 맞으십니다`.
- **지나친 높임.** `-실게요`는 듣는 사람의 행동에 말하는 사람의 약속을 붙인 꼴이다. `이쪽에 앉으실게요` → `이쪽에 앉아 주세요`. 명령, 제안, 질문 중 무엇인지 보고 고른다. 검사기는 `-실게요`도 알린다.
- **객체 높임.** 높일 사람에게 하는 행동은 `드리다`, `모시다`, `여쭙다`, `뵙다`, 조사 `께`를 쓴다.
- **자기 낮춤.** `저희`는 듣는 사람이 포함되지 않을 때만 쓴다. 나라를 말할 때는 `우리나라`다.

## 문장 성분 호응

- 주어와 서술어: `이 작업의 목표는 응답 시간을 줄였습니다` → `이 작업의 목표는 응답 시간을 줄이는 것이었습니다` 또는 `이 작업으로 응답 시간을 줄였습니다`.
- 목적어와 서술어를 나눠 맞춘다: `설계와 테스트를 작성했다` → `설계를 하고 테스트를 작성했다`.
- 대등하게 잇는 말은 꼴을 맞춘다: `로그 수집, 대시보드 구축, 알림을 보냈다` → `로그를 모으고 대시보드를 만들고 알림을 보냈다`.
- 짝이 있는 부사: `결코 ~ 않다`, `비록 ~지만`, `왜냐하면 ~ 때문이다`, `만약 ~면`.
- 한 문장에 기간, 대상, 행동, 결과가 다 들어가 호응이 엉키면 문장을 나눈다.

## 뜻이 겹치는 말

같은 뜻을 두 번 말하면 하나를 덜어 낸다. 일부러 힘주어 반복한 것이면 둔다.

| 겹친 말 | 고친 말 |
|---|---|
| 미리 예약했다 | 예약했다 |
| 다시 재시작했다 | 다시 시작했다 / 재시작했다 |
| 함께 협업했다 | 협업했다 / 함께 일했다 |
| 서로 상호 검토 | 상호 검토 / 서로 검토 |
| 가장 최적의 | 최적의 / 가장 알맞은 |
| 새로 신설한 | 신설한 / 새로 만든 |
| 과반수 이상 | 과반수 |
| 접수받았다 | 접수했다 / 받았다 |
| 약 3시간 정도 | 약 3시간 / 3시간 정도 |

## 행정 말투와 일본어투

공지, 안내, 사내 문서에서 굳은 서식 말투는 쉬운 말로 푼다. 법령, 계약, 규정에 정의된 말은 그대로 둔다.

| 굳은 말 | 쉬운 말 |
|---|---|
| 상기 내용 | 위 내용 |
| 금번 | 이번 |
| 익일 | 다음 날 |
| 규정에 의거하여 | 규정에 따라 |
| 검토를 요함 | 검토해야 함 / 검토가 필요함 |
| 허가를 득한 | 허가를 받은 |
| 소정의 양식 | 정해진 양식 |
| 제반 사항 | 여러 사항 / 모든 사항 |
| 기 제출한 | 이미 낸 |
| 수순 | 순서, 절차 |
| ~할 것 (안내문 끝) | ~해 주세요 / ~하기 바랍니다 |

## 표기 일관성

한 문서 안에서 같은 것은 같게 쓴다. 고치기 전에 문서 전체에서 많이 쓴 쪽을 찾고 그쪽으로 맞춘다.

- 같은 개념은 같은 용어로: `로그인`, `로그 인`, `사인인`이 섞이면 하나로. 영문 이름의 대소문자(`GitHub`, `Github`)도 맞춘다.
- 숫자와 단위: `10GB`, `10 GB`, `10기가`가 섞이면 하나로. 값은 그대로 둔다.
- 날짜와 시간: `2026-10-05`, `2026.10.05.`, `2026년 10월 5일` 중 하나로. 마침표로 쓰는 날짜는 `2026. 10. 5.`처럼 끝에도 찍는다.
- 목록 항목의 끝: 명사형(`~구축`, `~함`)과 문장형(`~했습니다`)을 한 목록 안에서 섞지 않는다.
- 약어는 처음 나올 때 한 번만 푼다. 독자가 다 아는 약어(API, URL)는 풀지 않는다.

## 제목과 라벨

제목, 표 머리, 버튼, 목록 머리말은 본문과 다른 자리다. 본문 종결을 끌어오지 않고 짧게 쓴다.

- `설치하는 방법을 알아봅시다` → `설치 방법` 또는 `설치`
- 감상형 제목(`첫걸음이 가벼웠다`) 대신 실제 내용(`설치 없이 브라우저에서 실행`)을 쓴다. 원문에 없는 기능을 제목에 넣지 않는다.
- 질문형 제목이나 동사형 버튼이 문서 관례라면 따른다.

## 글자 수

자기소개서, 지원서 문항, 공모 양식처럼 한도가 있으면 먼저 공백 포함인지 제외인지 확인한다. 모르면 둘 다 적는다. 줄바꿈을 세는 방식은 사이트마다 달라서 한도에 딱 맞추지 말고 조금 여유를 둔다.

```bash
python3 scripts/check_revision.py --after 결과.txt --limit 500            # 공백 포함 500자
python3 scripts/check_revision.py --after 결과.txt --limit 500 --no-spaces  # 공백 제외
```

글자 수를 눈대중으로 짐작하지 않는다. 한도를 채우려고 군말이나 없는 내용을 보태지 않는다. 넘치면 겹친 말과 수식부터 덜고, 그래도 넘치면 무엇을 뺄지 필자에게 묻는다.
