# Layout

## Canvas and grid (inches, 16:9)

| item | value |
|---|---|
| slide | 13.333 × 7.5 |
| safe margins | left/right 0.56, top 0.42, bottom 0.34 |
| header band (title) | top 0.42, height ≈ 0.78 |
| footer band (source, page) | bottom 0.34, height ≈ 0.28 |
| content area | x 0.56–12.77, y ≈ 1.35–6.85 |
| gutter between cards | 0.20–0.30 |
| card inner padding | 0.18–0.25 |

Nothing but a full-bleed background may cross the safe margins. Align every block to a shared left edge and a shared top line; equal cards get equal width and height.

## Families

| family | use when | structure |
|---|---|---|
| hero_assertion | one claim, or one number framing the deck | large title + one metric or statement, generous whitespace |
| proof_grid | 3–6 evidence claims | 2×2 (4) or 1×3 / 2×3 cards; each card = short claim + two-line reason; numbered or rail-marked |
| metric_strip | 2–4 numeric facts | row of metric cards: big value, short label, one-line meaning |
| comparison_2col | two options | two equal columns, same criteria order, a small "vs" badge between, recommended side accented |
| process_flow | 3–6 ordered steps | row of steps with numbered discs and arrows; label + one-sentence detail |
| table_focus | lookup grid | native table, header row filled, zebra rows, ≤ 6×7 |
| chart_focus | user-supplied series | native bar/line chart + one-line conclusion beside or above it |
| quote_proof | attributed principle or voice | quote with attribution + 2–3 supporting bullets beneath |
| recommendation | the ask / next action | band or full-width panel: action, owner, timing, success metric |

If the content does not fit the family, change the family or split the slide. Do not stretch one card to fill the canvas: a card taller than its text (empty lower half) means the block is too thin — add the reason text or choose another family.

## Fill the canvas honestly

- No large empty area under the last block. If one remains, the takeaway band (a short conclusion strip at the bottom of the content area) belongs there, and it must not repeat the title.
- A slide that is mostly empty cards floating mid-canvas fails review.
- Footer: deck title (shortened, never a lone `…`), source, page number.

## Motion

Optional and minimal: a fade between slides; build process / comparison / proof elements on click only for live decide and pitch talks. Reports stay still.
